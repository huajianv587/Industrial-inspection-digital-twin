# 评测方案：从软件验收到模型评估

## 当前仓库可评测的内容

运行 `python -m inspection_system.cli evaluate` 会执行固定的确定性验收用例，例如高温、压力超限、柜门未关和空观测。输出中的 `acceptance_pass_rate` 只代表这些软件用例的通过比例，**不是模型准确率、召回率或现场表现**。

## 后续感知模型评估

### 表计读数

- 数据：独立划分的合成图像测试集；训练/验证/测试应按场景、设备实例、相机视角或随机种子分组，避免相邻帧泄漏。
- 指标：MAE、RMSE、读数有效率、超量程拒识率；按视角、距离、照明分层报告。
- 单位：MPa。误差阈值需由量程、设备精度和业务需求决定，不能先写一个漂亮数字再倒推结果。

### 异常分类 / 检测

- 指标：Precision、Recall、F1、PR-AUC；检测任务还需 mAP、定位误差或 IoU。
- 对正常/异常类别不均衡的情况报告每类指标和混淆矩阵。
- 对“泄漏”类需要说明视觉外观与真实泄漏的差异，不能将纹理识别直接等同于介质泄漏确认。

### 热成像

- 先明确输出是温度回归还是热区定位。
- 温度回归需使用有辐射测温真值、校准参数与环境条件的数据；报告 MAE/RMSE 和分温区误差。
- 只有伪彩色图时，不能把像素颜色当作真实温度真值。

### 系统级巡检

- 航点到达率、任务完成率、任务耗时、平均重试次数、感知服务超时率、工单生成完整率。
- 记录失败任务，不得只统计成功任务。
- 通过固定 seed 重复运行，保存配置、日志、软件版本和输出文件。

最终需包含独立场景/设备实例测试、域外测试，并在条件允许时使用人工复核的真实样本做外部验证。仿真指标与真实场景指标应分开报告。
