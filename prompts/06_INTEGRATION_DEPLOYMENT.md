# Phase 6：系统集成、可观测性与部署

## 目标
让系统能从干净环境重建、运行、观测和排错，仍保留离线模式。

## 任务
- 统一配置管理与启动入口；启动前验证依赖、资产路径、topic、数据库和工单服务健康状态。
- 记录应用版本、git commit、Isaac Sim 版本、ROS 2 发行版、驱动、Unitree SDK、模型和数据版本。
- 增加结构化日志、trace/run ID、日志轮转、指标采集和故障告警。
- 对节点崩溃、topic 丢失、磁盘不足、数据库不可用和模型超时做故障注入。
- 使用容器或锁定依赖文件固化可复现环境；说明 Isaac Sim 许可/安装方式，不把庞大专有资产打入公共镜像。
- 增加 CI：格式/静态检查、单元测试、离线端到端测试、接口 schema 检查。
- 部署前完成机器人运动风险评估、网络安全检查、急停验证、人工接管流程和权限审查。

## 验收
从干净机器按 README 安装；所有测试真实通过；给出部署配置、健康检查结果、失败恢复证据和未解决风险清单。未在目标环境运行的部分必须标记 `NOT_VALIDATED`。
